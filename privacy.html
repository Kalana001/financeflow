Privacy Policy

Last updated: July 28, 2026

FinanceFlow ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy details how we process user data.

1. Data Collection & Safety

FinanceFlow operates on a minimal data collection model. We do not support file uploads, image attachments, or external document scans inside version 1 to minimize storage vulnerabilities.

2. Row-Level Security and Database Isolation

All transactions, budgets, and savings goals are stored in an encrypted Supabase PostgreSQL database. Access is strictly isolated by user ID via Row Level Security (RLS) policies. No user can read or modify another user's records.

3. User Control & Compliance

Users have complete control over their information, including:

  • Downloading their complete profile and cashflow records as a JSON file at any time.
  • Permanently deleting their account and purging all records from our database.
